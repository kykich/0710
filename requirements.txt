# Зависимости проекта.
#
# Проект почти не требует сторонних пакетов: сервер, отдача файлов,
# обработка форм — всё на стандартной библиотеке Python 3.7+ (http.server,
# urllib, json, re, threading, mimetypes, pathlib и т.д.).
#
# Внешняя зависимость — пакет \mcp\ (Model Context Protocol): нужен ТОЛЬКО
# для MCP-слоя (подключение к MCP-серверу, list_tools/call_tool, см.
# rtk_app/mcp_client.py, client.py, yandex_calendar_server.py). Зависимость
# ОПЦИОНАЛЬНАЯ: веб-сервер запускается и без неё — тогда статус MCP в
# интерфейсе будет «недоступен (не установлен пакет mcp)».
#
# Требуется Python >= 3.9 (для пакета mcp).
#
# Установка:  pip install -r requirements.txt
mcp


caldav
# \caldav\ (+ его зависимость \icalendar\) нужны для MCP-сервера
# Яндекс.Календаря (yandex_calendar_server.py: list_events/create_event/…).
# Без них импорт падает: No module named 'caldav'.
icalendar

# MCP-сервер «Время» (currency_server.py) дополнительных зависимостей НЕ
# требует: значение берётся из локального времени (datetime), внешних вызовов
# нет. Того же требуют MCP-серверы «Погода» (weather_server.py, OpenWeatherMap)
# и «Замполит» (zampolit_server.py): только стандартный urllib.

pypdf
# \pypdf\ нужен ТОЛЬКО для RAG-слоя (rtk_app/rag.py): извлечение ТЕКСТОВОГО
# СЛОЯ из PDF-документов при индексации. Зависимость чистого Python (без
# бинарных колёс/OCR), картинки и графика НЕ извлекаются — берётся только
# текст (PDF, сконвертированные из Word, имеют текстовый слой).
# Зависимость ОПЦИОНАЛЬНАЯ: без неё RAG-индексация вернёт ошибку
# «нет библиотеки pypdf», а остальной сервер работает как обычно.
