Задача: Сделать несколько иструментов MCP.
(для данного режима сделать отдельную кнопку для запуска композиции в разделе MCP).
Пайплайн:
1."календарь" проверяет каждую минуту состояние событий на ближайшие 7 дней с текущей даты.
2. "конвертер" получает данные о курсах валют.
3. "замполит" mcp сервер берет данные с калндаря. Если событие с 0.00 до 12.00 запрашиваем курс долара к юаню. 
Если событие с 12.00 до 24.00 запрашиваем курс евро к долару.
4. "завхоз" mcp сервер который берет данные от "замполита" и сохраняет результат в json файл.
5. "доска" mcp сервер который по запросу пользователя в чате выводит данные "завхоз". в виде таблицы где сопоставленны события и курс валют.
